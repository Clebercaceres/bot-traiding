  git commit -m "deploy: enable psycopg2 for production"
  git push origin main

PASO 8 — Verifica que funciona:

── 5A. CREAR KEYSTORE (FIRMA DE LA APP) ──────────────────────
  Solo se hace UNA VEZ. Guarda estos archivos para siempre.

  PASO 1 — Genera el keystore:
    cd "C:\Users\MI PC\Documents\GitHub\bot-traiding\app"
    keytool -genkey -v -keystore tradebot-keystore.jks -keyalg RSA -keysize 2048 -validity 10000 -alias tradebot

    Te pedirá:
      - Contraseña del keystore (guárdala, la necesitas siempre)
      - Nombre, organización, país (puedes poner lo que quieras)

  PASO 2 — Crea el archivo android/key.properties:
    Crea el archivo: app\android\key.properties
    Con este contenido (cambia los valores):

      storePassword=TU_CONTRASEÑA_KEYSTORE
      keyPassword=TU_CONTRASEÑA_KEYSTORE
      keyAlias=tradebot
      storeFile=../tradebot-keystore.jks

  PASO 3 — Configura android/app/build.gradle para usar el keystore:
    Abre: app\android\app\build.gradle
    Agrega arriba del bloque android { ... }:

      def keystoreProperties = new Properties()
      def keystorePropertiesFile = rootProject.file('key.properties')
      if (keystorePropertiesFile.exists()) {
          keystoreProperties.load(new FileInputStream(keystorePropertiesFile))
      }

    Dentro de android { ... }, agrega signingConfigs y modifica buildTypes:

      signingConfigs {
          release {
              keyAlias keystoreProperties['keyAlias']
              keyPassword keystoreProperties['keyPassword']
              storeFile keystoreProperties['storeFile'] ? file(keystoreProperties['storeFile']) : null
              storePassword keystoreProperties['storePassword']
          }
      }
      buildTypes {
          release {
              signingConfig signingConfigs.release
          }
      }

── 5D. SUBIR A PLAY STORE ────────────────────────────────────

  PASO 1 — Entra a Google Play Console:
    https://play.google.com/console

  PASO 2 — Crea nueva app:
    - Create app → nombre: TradeBot → idioma: Español → App → Free

  PASO 3 — Completa la información requerida:
    - App content: responde las preguntas de contenido
    - Store listing: descripción, screenshots (mínimo 2), ícono 512x512
    - Content rating: completa el cuestionario
    - Target audience: selecciona 18+

  PASO 4 — Sube el bundle:
    - Testing → Internal testing → Create release
    - Upload → selecciona el archivo app-release.aab
    - Guarda y publica la prueba interna

  PASO 5 — Prueba con testers internos (tu correo):
    - Agrega tu email como tester interno
    - Instala desde el link de prueba

  PASO 6 — Cuando esté listo, publica en producción:
    - Production → Create release → sube el mismo .aab
    - Review and publish

  TIEMPO DE REVISIÓN: Google tarda 1-7 días en aprobar apps nuevas.

── 5E. ACTUALIZACIONES FUTURAS ───────────────────────────────

  Para cada update:
  1. Sube el versionCode en pubspec.yaml: version: 1.0.1+2
  2. flutter build appbundle --release
  3. En Play Console → Production → Create new release → sube el nuevo .aab
